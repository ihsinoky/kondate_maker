# kondate_maker 要件（現時点）

## 1. 目的（プロダクトが解決したいこと）
週次の献立作成において、以下の「探す・選ぶ」の負担を減らす。
- 旬（安価・良質）を踏まえたレシピ候補を探す手間
- 曜日ルール（水曜鯖、金曜スープ）を守りつつ、迷わず決める手間
- 複数レシピで食材を使い回す（汎用性の高い食材を優先）という戦略に沿って組む手間
- Notionへ貼る形式に整える手間

## 2. 利用者と利用条件
- 利用者：2名（PO本人＋妻）
- 同時利用：しない
- 端末：最終はそれぞれのiPhone + 共通端末としてiPadも利用

## 3. 週テンプレ（固定仕様）
- 並び：土→金
- レシピ枠：合計9枠
  - 土：昼1／夜1
  - 日：昼1／夜1
  - 月：夜1
  - 火：夜1
  - 水：夜1（冷凍鯖）
  - 木：夜1
  - 金：夜1（スープ）

## 4. 入力
### 4.1 旬の食材（テキスト入力）
- 形式（提案）：1行1食材（複数行可）
- 意味：その週に「メインで買う食材」候補
- 戦略：1つの食材を「2回分のレシピで使う」イメージ（複数食材でも良い）

### 4.2 設定（Config）
- 水曜（冷凍鯖）候補URL：複数登録（3パターン想定）
  - 入力：`タイトル | URL` または `URL`
- 将来拡張（後述）：除外食材、調理法制約など

## 5. 出力（MVP〜）
### 5.1 メイン画面（MVP）
- 9枠のレシピカード
  - 表示：タイトル、URL（タップで開く）、出典、警告（必要時）
- 画面下部に「買い出しリスト」領域（MVPでは未対応表示のみ）

### 5.2 Notion貼り付け用（MVP）
- 見出し中心のMarkdown風テキストをコピー
- 例：
  - `## 土（昼）`
  - `- 料理名（出典） URL`

## 6. 制約・ルール
### 6.1 曜日固定
- 水曜夜：冷凍鯖（設定した3候補からランダム）
- 金曜夜：スープ系（簡易判定で優先。候補不足は警告）

### 6.2 調理時間
- 目安：30分以内
- ただし、厳格除外はしない（“要注意”ラベル等で扱う方針）

### 6.3 旬反映
- POが入力した旬食材を、候補収集・選定で「優先」する（必須ではなく加点）

### 6.4 食材の使い回し（重要方針）
- 週のメイン食材（旬入力）を軸に、複数レシピで使い回す献立を優先
- 最初は「タイトル／タグ／検索キーワード」ベースの簡易戦略で開始し、精度は段階的に上げる

## 7. 優先するレシピソース
- サイト（優先）：白ごはん.com / Nadia / つくおき
- 料理家（優先）：りなてぃ（Nadia）
- 方式：各サイトの検索／一覧ページからURL候補を取得（外部検索APIは使わない）

## 8. スコープ外（当面やらない）
- Notion連携（データベース読み書き）
- レシピ本文の取り込み（材料・手順・画像等）
- 買い出しリスト生成・統合
- 自宅向け読み替え／分量換算
- 過去レシピ検索（履歴DB）
