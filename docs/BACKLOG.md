- **Notion API呼び出しをバックエンドへ移行（セキュリティ強化）**
  - **現状の課題**: VITE_NOTION_TOKENを使用しており、トークンがブラウザバンドルに露出
  - **目的**: 本番環境でのセキュリティ強化（現在は個人利用・開発目的のみを想定）
  - **実装案**:
    1. バックエンドAPI（例: `/api/notion/recipes`, `/api/notion/meal-logs`）を追加
    2. バックエンドでNotion APIを呼び出し（トークンはサーバー側環境変数として管理）
    3. フロントエンドはバックエンドAPIを呼び出すように変更
    4. VITE_NOTION_TOKEN環境変数を削除
  - **利点**:
    - トークンがブラウザに露出しない
    - 本番環境での安全な利用が可能
    - レート制限やキャッシングをバックエンドで制御可能
  - **実装難易度**: 高（アーキテクチャ変更が必要）
  - **参照**: M1実装でセキュリティ警告をドキュメントに明記済み（コミット: 11a924a）
