   - 受け入れ条件：方式が1つに決まり、実装の入口（モジュールやAPI）が決まっている

2. **Nadia（りなてぃ）候補取得モジュール（P0-2）**

3. **つくおき候補取得モジュール（P0-3）**
   - 前提：P0-0の決定事項（Q4: 食材プール用語統一）
   - 受け入れ条件：候補が一定数取れ、金曜スープの候補不足が減る

4. **白ごはん.com候補取得モジュール（最低限）（P0-4）**
