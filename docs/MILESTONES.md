# マイルストーン

## M0 / v0.1（達成）
- 9枠表示（週テンプレ固定：土→金、土日昼夜、平日夜）
- Notion貼り付け用コピー（見出し中心）
- 水曜鯖（設定候補からランダム）
- 金曜スープ優先（不足警告）
- 買い出しリスト領域は未対応表示

## M1 / v0.2（次：合格ライン＝「9枠が実在URLで埋まる」）
- 9枠が、毎回「実在するURL（外部ソース）」で埋まる
- ルール：
  - 水曜：鯖（設定候補）
  - 金曜：スープ（候補不足なら警告）
- 候補不足や取得失敗があってもアプリは落ちない（警告＋フォールバック）

## M2 / v0.3（使い勝手の改善）
- 生成結果の保持（週の状態が勝手に変わらない）
- 枠単位の再提案／固定
- 旬入力の反映（優先度づけ）を明確化

## M3 / v0.4（設定の拡張・生活適合）
- 除外食材（ナッツ）設定
- 平日揚げ物回避設定
- 設定エクスポート/インポート（端末間共有の最小実装）

## M4以降（大機能）
- 買い出しリスト生成・統合
- 自宅向け読み替え・分量換算
- 過去レシピ検索（履歴）
